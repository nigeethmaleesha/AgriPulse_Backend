
# AgriPulse Backend - PDSA2 Module 2 Resource Allocation

Integrated runtime: port `8083`, database `agripulse_module2_allocation`, PostgreSQL user `postgres`, password `1234`, frontend proxy `/module2-api`.

Start the shared PostgreSQL service from the project-root `docker-compose.yml`, then run `.\mvnw.cmd spring-boot:run`.

For the complete startup order and mapping, see the project-root `RUN_GUIDE_SINGLISH.md`.
